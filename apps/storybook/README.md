# Parya Storybook

This application lives in the same repository as `packages/web` and `apps/docs`. It renders shared components and examples; it contains no second component implementation.

From the repository root:

```sh
npm ci
npm run dev:storybook
npm run build:storybook
npm run test:storybook
```

`npm run dev` starts documentation and Storybook together. Stories are generated by `scripts/generate-stories.mjs` from the shared catalog and `design/playground-controls.json`. Change component code and examples in `packages/web/src`. Edit shared control defaults in `design/playground-controls.json`; do not edit generated stories manually.

The static build is `apps/storybook/storybook-static/`, generated during the build and ignored by Git. See the root DEPLOYMENT.md for Vercel configuration. All components remain experimental.
