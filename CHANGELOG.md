## 0.1.0 — 2026-10-28

Initial experimental release: React components built from Paper, shared examples, documentation portal, exact token and SVG exports, generated APIs and Markdown, LLM documentation endpoints, four reusable hooks, and a connected separate Storybook application.

This version is not published to npm and does not implement every component or variant in Paper. See PRODUCTION.md and the website's Design coverage page.
